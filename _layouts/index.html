Open Source · ISO 20022 · CBPR+ 2026 Ready

Interbank credit transfer clearing your central bank will not reject.

pacs008 turns legacy SWIFT MT103 FIN blocks, CSV, and internal payment data into schema-validated pacs.008.001.13 XML, with CBPR+ and Bank of England CHAPS 2026 structured address enforcement built in.

See it live › Why pacs008 Read 2026 Briefing
terminal — 60 seconds to a validated pacs.008 file 
# Install the pacs008 suite
pip install pacs008 pacs008-loader-mt103 pacs008-mcp

# Convert legacy SWIFT MT103 to validated pacs.008.001.13 XML
pacs008 -t pacs.008.001.13 -d mt103-payment.txt -o out/

# Prove it clean against SWIFT CBPR+ 2026 rules (exit 0 = valid)
pacs008 -t pacs.008.001.13 -d payments.csv --scheme cbpr-plus --dry-run

Runs entirely on your machine — zero payload storage, no network telemetry. Read the privacy position.
