Try pacs008 in Your Browser

Drop in a CSV, use the sample, or paste your own records — payment payloads are processed locally by your browser and are not transmitted to pacs008.com. Follow your organization's data-handling policy and use synthetic or masked test data where required.

How this validator helps you

  • ✓Test payment data against the checks banks apply — required fields, IBAN checksums, BIC structure, control totals
  • ✓Generate a working pacs.008.001.13 credit-transfer file with mandatory ChrgBr elements
  • ✓Validate ISO 13616 IBAN mod-97 and ISO 9362 BIC structures directly in your browser

Important information

  • Local processing only. Payment payloads are processed locally by this page and are not transmitted to pacs008.com. Zero payment-payload storage.
  • Testing tool only. Files are never submitted for processing and no payments can result from anything you do here.
  • Expected columns: id, payment_id, payment_amount, currency, requested_execution_date, debtor & creditor name / IBAN / BIC.
  • Open source. Core toolkit is released under the Apache License 2.0.

Batch address readiness scan

Upload a CSV of party addresses to see how many records would still be accepted after 14 November 2026, when fully unstructured postal addresses are removed from the applicable CBPR+ and CHAPS flows.

The file is read in this page and classified in memory. It is not uploaded, not stored, and not logged. Use masked or synthetic data if your policy requires it.


Recognised columns: street, building_no, town, country, address_line1, address_line2, party, name. Names are matched loosely, so TwnNm and town_name both work.

Classification uses the same rules as the address checker above, so a batch result and a single record cannot disagree.
