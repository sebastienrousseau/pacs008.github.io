Installation

Install pacs008

Get the ISO 20022 pacs.008 toolkit running on Python in a few minutes — the core library, the FastAPI service, the MT103 loader and the MCP server for agents.

1. Requirements

pacs008 is a pure-Python suite. You need Python 3.10 or newer and pip. It runs on Linux, macOS and Windows. Every package in the suite is Apache-2.0 licensed and fully typed, shipping a py.typed marker so your editor and mypy get complete type information out of the box.

python --version   # 3.10 or newer

A virtual environment is recommended so the toolkit and its dependencies stay isolated from the rest of your system.

python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate

2. Install the core

Install the core library from PyPI. The current release is v0.0.8.

pip install pacs008

3. Quick start (core)

Build a payment record and generate a validated pacs.008 XML string. The snippet below is illustrative — the exact function names and record shape may differ between releases.

from pacs008 import generate_xml_string, process_files

# A single FI-to-FI customer credit transfer, as a plain data record.
record = {
    "message_id": "MSG-20260727-0001",
    "amount": "1500.00",
    "currency": "EUR",
    "debtor": {
        "name": "Acme Trading Ltd",
        "iban": "GB29NWBK60161331926819",
        "agent_bic": "NWBKGB2L",
    },
    "creditor": {
        "name": "Fournisseur SARL",
        "iban": "FR7630006000011234567890189",
        "agent_bic": "AGRIFRPP",
    },
    "remittance_info": "Invoice 2026-4471",
}

# Generate a scheme-aware, XSD-validated pacs.008 document.
xml = generate_xml_string(record, scheme="SCT_INST")
print(xml)

# Or process records in bulk from files on disk.
process_files(input_dir="records/", output_dir="out/")

Full API details, supported schemes and the exact signatures live in the GitHub README.

4. Validation

pacs008 validates on the way in and on the way out. Incoming records are checked against a JSON Schema; IBANs are verified with the ISO 13616 checksum across 75 countries; and every generated document is checked against the official XSD for its pacs.008 version. In short, malformed party data is caught before submission, not after a rejection from the network.

Validation runs before the message ever reaches a payment rail, so structured-address and party-data problems surface at build time rather than in a repair queue.

5. Run the API service

The core library ships a FastAPI service for automated workflows. Run it with uvicorn:

uvicorn pacs008.api:app --host 0.0.0.0 --port 8000

The service exposes endpoints such as /api/health, /api/validate and /api/generate. Endpoint paths are illustrative — check the README for the routes shipped in your version.

6. Install the MT103 loader

The MT103 loader bridges legacy SWIFT MT103 payloads into clean pacs.008 records. Install it from PyPI (current release v0.0.3):

pip install pacs008-loader-mt103

Parse an MT103 string into a record the core library can consume (illustrative):

from pacs008_loader_mt103 import parse_mt103
from pacs008 import generate_xml_string

record = parse_mt103(mt103_text)
xml = generate_xml_string(record, scheme="CBPR_PLUS")

Source and details: PyPI · GitHub.

7. Install & wire the MCP server

The MCP server exposes fifteen tools over stdio, backed by the core library, so agents in Claude, Cursor and Zed can read and edit pacs.008 safely. Install it from PyPI (current release v0.0.6):

pip install pacs008-mcp

Then register it in your MCP client configuration. The example below adds a pacs008-mcp entry launched over stdio:

{
  "mcpServers": {
    "pacs008": {
      "command": "pacs008-mcp",
      "args": []
    }
  }
}

Source and details: PyPI · GitHub.

8. Next steps

Read the documentation for the full API, or compare the three packages to decide what to adopt.
