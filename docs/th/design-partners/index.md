# พันธมิตรออกแบบ

## ยังไม่มีกรณีศึกษาที่นี่

นี่เป็นความตั้งใจ โครงการนี้ทุ่มเทอย่างมากในการตัดข้อกล่าวอ้างที่พิสูจน์ไม่ได้ออกไป และการแต่งเรื่องลูกค้าขึ้นมาย่อมทำให้ความพยายามนั้นสูญเปล่า เมื่อมีกรณีศึกษาปรากฏที่นี่ จะระบุชื่อองค์กรโดยได้รับอนุญาต และบอกเล่าสิ่งที่เกิดขึ้นจริง

หากคุณกำลังประเมิน pacs008 และต้องการผู้อ้างอิง โปรดบอกเรา แล้วเราจะตอบตามตรงว่ามีหรือไม่

## พันธมิตรออกแบบคืออะไร

องค์กรที่กำลังนำข้อความชำระเงิน ISO 20022 มาใช้ พร้อมทดสอบกับข้อกำหนดจริงและบอกเราว่าเครื่องมือยังขาดตรงไหน โดยทั่วไปคือธนาคาร ผู้ให้บริการชำระเงิน ฝ่ายบริหารเงินขององค์กร หรือผู้จำหน่ายซอฟต์แวร์ชำระเงิน

## สิ่งที่เราขอ

- รัน pacs008 กับโปรไฟล์ข้อความของคุณเอง ไม่ใช่เพียงตัวอย่าง
- บอกเราว่าคุณขาดกฎสคีมาใดและกำหนดส่งของคุณคือเมื่อใด
- รายงานข้อบกพร่องให้แม่นยำพอที่จะทำซ้ำได้: ประเภทข้อความ โปรไฟล์ วันที่มีผลบังคับ และผลลัพธ์ที่คาดหวัง
- แจ้งเราหากกฎที่เผยแพร่ไว้ผิด การแก้ไขกฎมาก่อนคุณสมบัติใหม่

เราไม่ขอข้อมูลการชำระเงิน ทุกอย่างทำซ้ำได้ด้วยระเบียนสังเคราะห์ และเราอยากให้คุณไม่ส่งข้อมูลจริงมาให้เราเลย

## สิ่งที่คุณได้รับ

- อิทธิพลโดยตรงต่อกฎสคีมาที่จะสร้างต่อไปและลำดับของมัน
- การแจ้งล่วงหน้าถึงการเปลี่ยนแปลงชุดกฎก่อนเผยแพร่ เพื่อไม่ให้พฤติกรรมที่เปลี่ยนไปทำให้กระบวนการของคุณสะดุด
- การเพิ่มกฎและไฟล์ทดสอบของคุณเข้าสู่ชุดที่รับรองแล้ว เพื่อไม่ให้รุ่นในอนาคตทำให้เสียหายอย่างเงียบ ๆ
- การให้เครดิตหากคุณต้องการ และไม่ให้เลยหากคุณไม่ต้องการ

## สิ่งที่เราให้ไม่ได้

- สัญญาสนับสนุนหรือการรับประกันความพร้อมใช้งาน นี่คือโครงการโอเพนซอร์สที่มีผู้ดูแลไม่กี่คน
- การรับรอง ผลการตรวจสอบที่ผ่านไม่ได้รับประกันว่าคู่สัญญาหรือผู้ดำเนินการสคีมาจะยอมรับข้อความนั้น
- การเก็บสิ่งที่คุณส่งทางอีเมลเป็นความลับ สำหรับเรื่องละเอียดอ่อน โปรดใช้ช่องทางรายงานด้านความปลอดภัย
