The pacs008 suite

Three composable, Apache-2.0, fully typed (py.typed) packages published on PyPI. Adopt only what you need — a core library, an MT103 loader and an MCP server that all share the same data model.

The pacs008 suite at a glance: what each package does, how to install it and when to reach for it.

pacs008 v0.0.8 Core: generate, validate, parse and audit pacs.008 (001.01–001.13), scheme profiles, IBAN/LEI/BIC and XSD validation, plus a FastAPI service. pip install pacs008 You need to produce or check pacs.008 messages.

The three packages in detail

pacs008 v0.0.8 · live

The core library

The foundation of the suite. Generate, validate, parse and audit pacs.008 across every published version from 001.01 to 001.13, with scheme-aware profiles for CBPR+, HVPS+, Fedwire, CHAPS, T2 RTGS and SCT Inst. IBAN, LEI and BIC checks run alongside full XSD validation, and a FastAPI service exposes the same logic for automated workflows.

PyPI · GitHub

pacs008-loader-mt103 v0.0.3 · live

MT103 migration loader

The pragmatic bridge out of legacy SWIFT. Feed it MT103 text and it produces clean pacs.008 records you can validate and enrich with the core library — no hand-mapping each field, and a repeatable path through MT → MX migration for institutions still carrying MT payloads.

PyPI · GitHub

pacs008-mcp v0.0.6 · live

MCP server for agents

Fifteen Model Context Protocol tools served over stdio, all backed by the core library so agents inherit the same validation guarantees. It lets AI assistants such as Claude, Cursor and Zed read and edit pacs.008 messages safely, span by span, instead of treating them as opaque text.

PyPI · GitHub

How they fit together

The packages are designed to compose. A typical flow starts with legacy input: MT103 payloads come in via the loader, which turns them into pacs.008 records. Those records are then validated and enriched with the core library — scheme rules, party data, IBAN/LEI/BIC and XSD checks applied before anything reaches the network. Finally, the same messages can be exposed to AI agents through the MCP server, so assistants read and edit them under the core library's rules rather than free-form.

Because every package is mypy --strict clean and ships py.typed, the types flow straight through to your own code: downstream imports type-check against the real signatures, so mistakes surface at authoring time rather than in production.

Quality bar

The suite is held to numbers we can stand behind. The core library carries 1,883 tests, while the loader and MCP server each sit at 100% coverage. All three packages are published on PyPI and signed, so what you install is what was released.
