ISO 20022 message schemas
=========================

These XML Schema files are produced by the ISO 20022 Registration Authority and
are served here so the browser workbench can validate messages locally.

pacs008.com is not the official ISO 20022 website. The sole source of
up-to-date materials and information on ISO 20022 message standards and the
Repository is https://www.iso20022.org/.

They are used under the ISO 20022 Intellectual Property Right Policy, which
states the material is intended to be used and reproduced freely by all
interested users. See https://www.iso20022.org/terms-use.

The Registration Authority provides this material "as is" and disclaims all
warranties. These files are a snapshot: the Repository is maintained and
updated frequently, so check the official site for the current version.

Each file records the ISO 20022 version it was generated from in an XML comment
at the top.
